# Prototyp panelu ośrodka egzaminacyjnego FlexWelder

Klikalny, statyczny prototyp panelu ośrodka egzaminacyjnego. Można go przeklikać bez logowania i pobrać raport z uwagami (.docx).

**Wszystkie dane w prototypie są fikcyjne.**

Adres strony: https://szymon-konieczny.github.io/flexwelder-prototyp/

## Jak zaktualizować

Podmień `index.html` plikiem z `makiety-poprawione/publikacja`, zrób commit i push. Skrypt `./aktualizuj.sh` robi to w jednym kroku. GitHub Pages przebuduje stronę po pushu.
